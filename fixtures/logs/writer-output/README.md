# Model writer fixtures

These synthetic files were generated by ichnos's PNML, PTML and DFG writers.
`crates/ichnos-io/tests/model_io.rs` constructs the inputs and checks the exact
bytes. The `writer-*` io goldens read these files with pm4py 2.7.23.8
(commit 24a3bf6). The PNML includes inhibitor/reset arcs, stochastic and data-net
declarations, and two alternative final markings; pm4py merges the markings.
